# Splunk Home Lab – SIEM & Threat Detection

## Project Overview

This project focuses on building a home lab environment to practice **SIEM operations, log analysis, threat detection, and security monitoring** using Splunk.

The lab aims to simulate real-world SOC workflows by collecting Windows system telemetry, analyzing security events, identifying suspicious activities, and mapping detections to the MITRE ATT&CK framework.

## Tools & Technologies

- **Splunk:** SIEM platform for log ingestion, searching, monitoring, and alerting.
- **Sysmon:** Windows system monitoring and event logging.
- **Hayabusa:** Windows Event Log analysis and threat detection.
- **MITRE ATT&CK:** Framework for classifying adversary tactics and techniques.

## Project Objectives

- Configure a Splunk home lab environment.
- Collect and analyze Windows event logs.
- Monitor system activities using Sysmon.
- Investigate security events with Hayabusa.
- Develop detection queries and identify suspicious behavior.
- Map detected activities to MITRE ATT&CK techniques.
- Gain practical experience in SOC analysis and threat detection.
